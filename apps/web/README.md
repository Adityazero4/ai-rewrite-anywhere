# Website

The landing page for [AIRewriteAnywhere](../../README.md), live at
**[ai-rewrite-anywhere.vercel.app](https://ai-rewrite-anywhere.vercel.app)**.

Next.js App Router, Tailwind, statically rendered. The only client-side JavaScript is the hero
demo; everything else is HTML by the time it reaches the browser.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
```

## Layout

```
app/
  page.tsx              the whole page — one component per section
  layout.tsx            metadata and the SoftwareApplication + FAQPage JSON-LD
  opengraph-image.tsx   the 1200×630 social card, rendered with next/og
  sitemap.ts robots.ts  generated at build time
  globals.css           design tokens, surfaces, and the ambient hero field
  icon.png              favicons, generated by tools/make-icon.swift
components/
  RewriteDemo.tsx       the hero animation
  ConsoleMark.tsx       the ASCII mark, printed to the browser console
lib/site.ts             copy, shortcuts, app list and FAQ — the page reads from here
```

Content lives in `lib/site.ts` rather than in the markup, so the FAQ feeds both the visible
accordion and the structured data from one source and the two cannot drift apart.

## Design notes

The palette comes from the one artifact every user of this app touches first: the macOS
text-selection highlight. The page is a text surface; selection blue is the only accent.

The hero demo carries the idea typographically — the draft is monospace, raw and typed; the result
is proportional and composed. The typeface change *is* the rewrite. The two drafts share one grid
cell so the window never reflows, and their crossfades are sequenced rather than simultaneous,
because two texts fading through each other in the same place is unreadable.

## Deploying

Pushes to `main` deploy through the Vercel Git integration. The project's Root Directory is
`apps/web`.

`NEXT_PUBLIC_SITE_URL` drives every canonical URL, the sitemap and the OG tags, so pointing a
custom domain at the site means changing one variable and redeploying — no other edits.
